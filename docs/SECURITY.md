# Безопасность

Custom SDA — **локальный** аутентификатор. Сетевые запросы нужны для Steam (логин, подтверждения, аватары), а не для хранения ваших секретов на стороннем сервере.

## Vault

- Файл: зашифрованный `vault.csda` (Argon2id + AES-256-GCM).
- Пароль задаёт пользователь; без пароля данные не восстанавливаются.
- Храните **коды восстановления Steam** отдельно от vault.

## Что не покидает backend в открытом виде

- `shared_secret`, `identity_secret`, сырые токены не отдаются в React.
- UI получает Guard-код, статусы сессии и DTO аккаунтов.

## Подтверждения (трейд / маркет)

Нужны одновременно:

1. `identity_secret` (из maFile),
2. Активная JWT-сессия (`tokens` в maFile формата [steamguard-cli](https://github.com/dyc3/steamguard-cli)).

Если сессия устарела — **Войти снова** на вкладке подтверждений или повторный импорт maFile. См. [CONFIRMATIONS.md](CONFIRMATIONS.md).

## Автоблокировка

**Настройки → Безопасность → Автоблокировка** — таймаут бездействия в секундах (`lock_timeout_secs`).

## Биометрия (Android / iOS)

- Опциональная разблокировка через системный биометрический cipher.
- Включение только после успешной проверки пароля vault.
- Смена пароля vault сбрасывает сохранённую биометрию.

## Перенос на телефон

QR + одноразовый 6-значный код; payload шифруется (AES-256-GCM). Подробности в `src-tauri/src/mobile_transfer.rs`.

## Обновления (desktop)

Скачивание установщика с GitHub Releases **без** minisign/Tauri signing keys — пользователь ставит вручную. См. [UPDATER.md](UPDATER.md).

## Репозиторий

Не коммитьте: `keys/`, `*.key`, содержимое maFile, пароли, `.env` с секретами.
