# Подтверждения Steam

Вкладка **Подтверждения** — аналог SDA: приём / отклонение ожидающих действий (трейд, маркет и т.д.).

## Что нужно для работы

| Условие | Откуда |
|---------|--------|
| `identity_secret` | maFile |
| JWT / refresh-токены (активная сессия) | maFile steamguard-cli или повторный вход в приложении |

Без сессии коды Guard на главной могут работать, но **список подтверждений — нет**.

## Сценарии в UI

1. **Аккаунт готов** (`has_session` + `has_identity`) — автоматически загружается список; кнопки **Обновить** и **Войти снова**.
2. **Нет сессии или identity** — экран выбора:
   - **Войти снова** — логин Steam для аккаунта из vault (обновление токенов).
   - **Импорт maFile** — файл или вставка JSON.

При входе для известного аккаунта показывается **текущий Guard-код** с копированием (как на главной).

## Rust API (для отладки)

| Команда | Назначение |
|---------|------------|
| `steam_session_begin` | Начать повторный вход |
| `steam_session_submit_code` | Код Steam Guard / email |
| `steam_session_continue` | Продолжить многошаговый логин |
| `steam_session_cancel` | Отмена |
| `confirmations_list` / `accept` / `deny` | Список и действия |

Состояние сессии хранится в `AppState.steam_session`.

## Совет по maFile

Предпочтительно экспорт из **steamguard-cli** с полным набором токенов. Старые maFile только с `Session` могут не хватать для market confirmations.
